# Cricsheet sample matches

These JSON files are official Cricsheet records used for Phase 1 parser and
match-engine verification. They are a small, representative T20 sample, not the
full Cricsheet corpus.

Source: https://cricsheet.org/

License: Open Data Commons Attribution License. See `LICENSE.txt`.

Do not add complete competition zip archives to the repository. Download extra
matches locally when needed:

- Men's IPL: https://cricsheet.org/downloads/ipl_json.zip
- Women's T20 Challenge: https://cricsheet.org/downloads/wtc_json.zip
- Women's Premier League: https://cricsheet.org/downloads/wpl_json.zip
- Unofficial T20 internationals: https://cricsheet.org/downloads/it20s_json.zip
- T20 internationals: https://cricsheet.org/downloads/

JSON format documentation: https://cricsheet.org/format/json/
